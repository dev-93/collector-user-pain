# 반복 유료 거래 관찰 — 합의 후 1차 비교

날짜: 2026-10-25. 담당: 팀장 `/root`, 실제 Codex 조사자 `/root/repeat_transactions`, 독립 비판자 `/root/transaction_critic`.
범위: 무료 공개 원문·공식 상품/정책 문서의 소수 판독. 고객 연락·코드 수정·자동 수집·유료 호출·Notion 쓰기 없음. 초기 비교 사이클을 마쳤으며 사업 진행 여부는 CEO 미결정이다.

## CEO가 승인한 탐색 기준

이번 대화 Q1~Q7 답변으로 확정:

- 개발·소프트웨어에 한정하지 않는다. 누구나 지나치는 반복 유료 거래와 구매 이유까지 관찰한다.
- 자영업자·외국인은 임시 범위였으며 특정 인구집단을 고정하지 않는다. 이미 지출하는 고객부터 비교한다.
- 국내외 모두 검토. 영어 판매·지원에는 AI를 활용할 수 있다. 실제 실시간 전화·협상 요구는 거래별로 점검한다.
- 고객의 과거 행동·지출 대화를 개발보다 앞에 둔다. 초기 직접 제공·공급자 조율도 가능하다.
- 장기적으로 본인은 원격 상담·판매·조율·품질 관리, 현장 작업은 공급자 수행을 우선한다.
- 재고 매입·시설 임대·직원 채용 등 큰 고정비 없이 주문 후 제공 가능한 거래부터 살핀다.
- 관찰 범위는 정기 관리/보충, 예약·서류·일정 조율, 작업자 선정·품질 확인, 맞춤 선택·준비다.

이는 탐색 기준의 승인이다. 아래 업종이나 특정 사업 진행, 고객 연락, 유료 실험을 승인한 것으로 확대하지 않는다.

## 고객·문제·운영 비교

### A. 정기 대행 이용자의 인수인계·진행 확인 부담

- 고객 가설: 반복 업무를 외부 비서/대행에 맡기는 소규모 사업 운영자. 비용 결정권·정확한 역할은 추가 확인.
- 실패 장면 가설: 담당자가 바뀌거나 결과 확인이 늦어 다시 설명·추적하는 일을 본인이 떠안는다. 담당자 교체 부담은 원문에 있으나 재설명 시간·누락 손실은 아직 가설이다.
- 지출 이유: 본인의 시간 확보와 업무 지속. 기존 월 대행에 대한 장기 이용 자기보고가 있다.
- 대안: 기존 비서 업체의 교체/관리자, 프리랜서 직접 계약, 본인 처리. 기존 업체가 대체 인력까지 제공하므로 1인이 같은 범위를 싸게 제공한다는 가정은 약하다.
- 접근/인바운드 가설: 특정 역할의 반복 업무 위임·인수인계·완료 기준을 다루는 검색 콘텐츠에서 자발적 상담을 받는다. 검색량·유입·접근 가능한 실제 고객은 아직 미검증.
- 수익 가설: 좁은 업무의 완료 결과에 대한 건별/반복 대행료. 월구독을 선결정하지 않는다.
- 1인 운영: 현장보다 원격 제공 가능성은 높지만 전화·고객별 예외·응대·인수인계가 수익을 소모할 수 있다.
- 최소 검증 제안: 같은 역할 3명의 최근 4주 위임 업무·실제 지출·누락·재설명 시간을 확인한다. 문제가 기존 업체 내 교체로 해결되거나 결과 단위로 맡길 이유가 없으면 범위를 바꾼다.
- 현재 판정: **우선 관찰 제안**. 비용·운영·접근 미확인으로 사업 확정/검증 실험실 승격은 하지 않는다.

### B. 원거리 소유주의 정기 현장 작업 완료 확인·재작업 조율

- 고객 가설: 본인이 자주 현장에 갈 수 없으며 이미 청소/관리 비용을 내는 소유주.
- 실패 장면 가설: 비용은 지급했는데 무엇이 완료됐는지 판단하기 어렵거나 누락·재작업 연락을 반복한다. 읽은 원문은 관리 가치에 대한 의문을 보여주며 실제 누락 손실은 아직 미확인.
- 대안: 코호스트·전문 관리사·청소팀 직접 계약·지인. 기존 수수료에 검수가 포함되면 별도 결제 이유가 약하다.
- 접근/인바운드 가설: 원거리 소유주가 찾는 작업 검수·관리비 비교·운영 범위 관련 검색 질문. 실제 도달 경로는 미검증. Airbnb 네트워크는 실적·평점 등 진입 조건이 있어 바로 쓸 유입원으로 가정하지 않는다.
- 1인 운영: 현장 공급자와 대체 인력 없이는 원격 상담이 긴급 배차·손해 대응이 될 수 있다. 야간 대응 제외·책임 범위·재작업 비용을 고객/공급자 양쪽과 확인해야 한다.
- 최소 검증 제안: 소유주 3명의 최근 4주 완료 확인·재작업 사례와 기존 지급 범위를 확인한다. 현장 파트너 견적과 본인 대응 시간을 포함해 남는 금액이 없거나 기존 관리비 내 업무면 해당 제안을 중단한다.
- 현재 판정: **비교 관찰 제안, A보다 운영 부담 높음**. 전면 숙소 관리 사업을 추천한 것이 아니다.

### 다른 두 유형의 해석

- 사무실 정기 보충은 반복 주문 구조지만 대형 공급자의 자동 배송이 강하다. 여러 업체의 누락·재예약에 별도 조율료를 지급하는 고객 원문이 확보되기 전에는 우선순위를 높이지 않는다.
- 맞춤 선택·준비는 공급자 의뢰 예시에서 거래 범위가 보인다. 그러나 선물·행사·이사 등은 같은 고객의 반복 구매인지, 계절성·일회성인지 아직 구분되지 않았다.
- 반려견 배설물 수거는 일상에서 지나치는 반복 유료 거래의 관찰 예시다. 한국에서 해외 현장작업자를 중개할 사업의 타당성은 미확인이다. 동선·객단가·공급자 직거래가 제약이므로 바로 진입 추천하지 않는다.

[Reddit 정책](https://support.reddithelp.com/hc/en-us/articles/42728983564564-Responsible-Builder-Policy)의 API/상업 승인 조건도 유지된다. 다음 판독에는 고객 역할, 최근 실패 사건, 발생 주기, 현재 공급자, 실제 지급 단위·금액, 공급자 포함 업무, 손실, 우회 행동, 재구매/해지 이유, 고객 접근 경로를 구분한다. '좋아 보이는 거래'와 '우리가 풀 별도 유료 문제'를 구분하는 목적이다.

## 현재 결정과 재개 위치

- CEO 확정: 위 탐색 기준. 대화 Q7 ‘예’로 비교 조사 시작 승인.
