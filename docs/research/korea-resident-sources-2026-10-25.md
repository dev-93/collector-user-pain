# 한국 거주 외국인 출처 조사 — 범위 확인

사용자가 제공한 [Notion 가설](https://app.notion.com/p/403eb93112d5817b800ddf6eeb176451)을2026-10-25 읽었다. 한국 거주 외국인 대상이며 해외 고객 전반 가설이 아니다. 시작일 미정·준비 상태. 새 공개 커뮤니티 최대3곳과 당근3곳의7일 비교는 제안된 검증 설계다. 이번 열람으로 실험을 시작하거나 당근 자동화를 승인한 것은 아니다.

사전 통과 기준: 최근7일 공개글20건 이상, 당사자 경험5건 이상, 손실 명시2건 이상, 원문·게시일·URL 접근 가능. 회원수나 검색 요약만으로 채택하지 않는다. 조사100건당·시간당 유효 독립 문제를 비교한다. 원문 열람 보고와 유효 증거 집계는 분리한다.

## 1차 확인 — 아직 채택 아님

| 후보 | 실제 직접 열람 | 현재 판정 |
|---|---|---|
| [Expat.com 한국 포럼](https://www.expat.com/en/forum/asia/south-korea/) | 목록 열람 가능. 최근 댓글로 표시된 소개글 외 상당수가 수개월~수년 전 활동. 이번 도구 결과는5일 전 수집 표시 | 거주자 적합성은 있으나 최신20건 기준 충족 미확인. 최신 본문/날짜 표본 확인 전 파일럿 미채택 |
| [Koreabridge 포럼](https://www.koreabridge.net/forums) | 공개 목록과 Living Q&A 범주 확인. 목록만으로 실제 최근 작성일 확인 못함 | 원문 최신성 미확인. 구인/매물과 고객실패 원문 분리 필요 |
| [Fornur Housing](https://www.fornur.com/community/boards/housing) | 검색 결과 후보 발견. 직접 열람은Cache miss | 검색 문구를 고객 증거로 사용하지 않음. 본문·작성자·날짜 미검증 |

일반 검색은 후보 사이트 발견에만 사용했다. 검색 결과를 매일 운영 수집하는 방식으로 확정하지 않았다. Reddit은 관련 토론 후보가 보이지만 기존 정책 검토상 자동 수집 허용이 미확인이므로 연결하지 않았다. Facebook·Kakao 가입/비공개방 탐색은 하지 않았다.

다음: 후보별 실제 최근 목록·본문·날짜·직접 경험 여부를 확인하고, 사전 기준을 충족하는 곳이3곳 미만이면 억지로 채우지 않는다. 허용 범위와 품질이 확인된 경로만 구현한다. 기존 ChatGPT 예약·Notion 기록은 수정하지 않았다.
